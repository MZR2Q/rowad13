# شات بوت اللوائح الطلابية 🎓

هذا المشروع هو نسخة أولية (MVP) لشات بوت مخصص للإجابة على استفسارات الطلاب بالاعتماد على لوائح وأنظمة جامعية محددة. يستخدم المشروع إطار العمل Flask و Google Gemini API (عبر مكتبة `google-genai`).

## الميزات
- لا يختلق إجابات عامة؛ الإجابة تكون **فقط** بناءً على النصوص الموجودة في قاعدة المعرفة.
- في حال عدم وجود معلومات كافية للإجابة، يرد البوت فوراً برسالة توضح ذلك دون استدعاء Gemini.
- يوضح المصادر (رقم المادة واسمها) التي استند إليها في إجابته أسفل الرد.
- واجهة مستخدم بسيطة وعربية (RTL).

## متطلبات التشغيل
- Python 3.8 أو أحدث.

## خطوات التشغيل محلياً

1. **إنشاء البيئة الوهمية (Virtual Environment):**
   ```bash
   python -m venv venv
   ```

2. **تفعيل البيئة الوهمية:**
   - في أنظمة Windows:
     ```bash
     venv\Scripts\activate
     ```
   - في أنظمة Mac/Linux:
     ```bash
     source venv/bin/activate
     ```

3. **تثبيت المكتبات المطلوبة:**
   ```bash
   pip install -r requirements.txt
   ```

4. **إعداد مفتاح Gemini API:**
   - قم بإنشاء ملف باسم `.env` في المجلد الرئيسي للمشروع (يمكنك نسخ محتويات `.env.example`).
   - أضف مفتاح API الخاص بك بداخل الملف:
     ```env
     GEMINI_API_KEY=your_real_api_key_here
     GEMINI_MODEL=gemini-2.5-flash
     ```

5. **تشغيل التطبيق:**
   ```bash
   python app.py
   ```
   سيتم تشغيل الخادم محلياً، ويمكنك زيارة الواجهة عبر المتصفح على الرابط:
   `http://127.0.0.1:5000`

## طريقة إضافة مواد جديدة
لإضافة مواد أو لوائح جديدة للبحث:
1. افتح الملف الموجود في المسار `data/regulations.json`.
2. أضف الكائن JSON الخاص بالمادة الجديدة داخل المصفوفة بنفس الهيكل المتوفر:
   ```json
   {
       "id": 6,
       "document_name": "اسم اللائحة",
       "article_number": "رقم المادة",
       "title": "عنوان المادة",
       "category": "التصنيف",
       "content": "نص المادة هنا...",
       "page": 1,
       "tags": ["كلمة", "مفتاحية"]
   }
   ```
