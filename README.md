> رصد ذكي، وإغلاق البلاغ **بعد التحقق**.
> الهاكاثون الهندسي · IECE 2026 — المسار 01 (المدن الذكية) · التحدي 05 (المدن ذاتية الإدارة) — فريق Twenty Thirty.

بروتوتايب تفاعلي بالكامل في المتصفح (**HTML/CSS/JS خام — بدون أي مكتبات أو خادم**) يحاكي فكرة **نَقاء**: تحويل شاحنة جمع النفايات إلى «عين ثانية على الشارع»، مع الفكرة الجوهرية: **فصل الكشف عن الإغلاق** — لا يُغلق البلاغ بإفادة الفريق، بل بتحقق آلي في مرور لاحق.

## التشغيل

مجرد ملفات ثابتة. افتح `index.html` في المتصفح مباشرة، أو انشره على GitHub Pages.

- ▶ **تشغيل / إيقاف** — جولة الشاحنة من الرصد إلى الإغلاق الموثّق.
- ⏭ **خطوة** — تقدّم إلى الرصد التالي ثم يتوقّف.
- **السرعة** ×1 / ×2 / ×4.
- 📣 **بلاغ مواطن** — يُدمج في الحدث القائم لنفس الموقع (دمج التكرار).
- ↺ **إعادة** · ⛶ **ملء الشاشة**.

## ما الذي تُبرزه المحاكاة

**بوابة الثقة:** ثقة ≥ 0.85 → أمر عمل تلقائي · من 0.60 إلى < 0.85 → قرار المشغّل · < 0.60 → لا طاقم، إعادة رصد.

**شروط الإغلاق الثلاثة معًا:** زوال التراكم + استمرار النظافة (مشاهدتان متتاليتان) + وضوح المشهد.

**الحالات:** `CLOSED_VERIFIED` (مغلق موثّق) · `REWORK_REQUIRED` (إعادة عمل) · `UNCERTAIN` (غير مؤكد) · مراجعة المشغّل.

**المؤشر:** `vTTC` (زمن التنظيف المؤكَّد) = وقت الإغلاق الموثّق − وقت أول رصد موثوق.

### ستة سيناريوهات تعمل تلقائيًا في الجولة

| الموقع | السيناريو | النتيجة |
|---|---|---|
| C1 | رصد عالي الثقة (0.91) → مروران نظيفان | مغلق موثّق + vTTC |
| C2 | إفادة الفريق لا تُغلق البلاغ — بقيت مخلفات | إعادة عمل، ثم إغلاق بعد التحقق |
| C3 | مركبة تحجب الحاوية عند التحقق | غير مؤكد → إعادة رصد → إغلاق |
| C4 | ثقة متوسطة (0.72) | اعتماد المشغّل → إغلاق بعد التحقق |
| C5 | ثقة منخفضة (0.48) | لا طاقم — تجنّب زيارة مهدورة |
| C6 | إخراج نظامي للنفايات في موعد الجمع | فئة سلبية — لا مخالفة |
